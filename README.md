# Hotel Management Desktop App

A Java Swing desktop application for managing hotel guests, rooms, bookings, check-ins, check-outs, payments, and services.

## Features

- Guest management — add, update, and delete guest records
- Room management — manage room availability and bookings
- Check-in and check-out tracking
- Payment and service management
- User-friendly desktop GUI built with Java Swing
- MySQL database connectivity using JDBC
- Hotel operation record management
- Login system for application access

## Technologies

- **Java**
- **Java Swing**
- **JDBC**
- **MySQL**
- **MySQL Connector/J**
- **rs2xml**
- **Object-Oriented Programming (OOP)**

## Windows Installation

The easiest way to run the application on Windows is to use the installer provided in the GitHub Releases section.

### MSI Installer

1. Download `Hotel Management System-1.0.0.msi` from the latest GitHub Release.
2. Open the downloaded `.msi` file.
3. Follow the Windows installation instructions.
4. Launch **Hotel Management System** after installation.
5. Use the demo credentials below to log in.

### Windows Executable

A Windows executable installer is also provided as:

`Hotel Management System-1.0.0.exe`

The MSI installer is recommended for Windows installation.

## ▶️Running the JAR

You can also run the original Java application directly using the JAR file.

Java must be installed on your computer.

```bash
java -jar Hotel_Managment_System.jar
```

The required dependency libraries are included in the `lib` folder.
