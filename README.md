# Hotel Management Desktop App

## Description
A Java desktop application designed to help manage hotel operations efficiently.  
This app allows users to:

- Add, update, and delete guest information
- Manage room availability and bookings
- Track check-in and check-out dates
- Maintain records of payments and services

This project demonstrates Object-Oriented Programming (OOP), GUI development, and file handling in Java.

---

## Features
- Guest management (add, edit, remove)
- Room booking and availability tracking
- Check-in and check-out management
- Payment and service tracking
- User-friendly GUI built with Swing

---

## Technologies Used
- Java
- jframe
